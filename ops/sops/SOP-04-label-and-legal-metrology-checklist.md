# SOP-04 Label and Legal Metrology pre-press checklist

Two laws apply at once: **FSS (Labelling & Display) Regulations 2020** and **Legal Metrology (Packaged Commodities) Rules 2011** (as amended 2022–2023). Miss one and the whole print run is scrap. Run this list on the artwork, and again on the printer's proof. Store approved proofs in `vault/06-brand/labels/` and register them in Ops → Documents (type `label-artwork`).

## A. The label

| ✓ | Item | Notes |
|---|---|---|
| ☐ | Name of the food | e.g. "Hazelnut flavoured instant coffee" — generic name, not just the brand |
| ☐ | Ingredients in descending order by weight | Include the flavouring, described correctly as **natural / nature-identical / artificial** flavouring substances |
| ☐ | Nutritional information per 100 g | Energy (kcal), protein, carbohydrate, total sugar, added sugar, total fat, saturated fat, trans fat, sodium. From a real lab analysis — never copied from a competitor |
| ☐ | Veg symbol | Green filled circle inside a green-outlined square |
| ☐ | Allergen declaration | If any dairy, nuts or flavouring carrier requires it |
| ☐ | **Manufactured by** | Manufacturer's name, full address, their FSSAI licence number |
| ☐ | **Marketed by** | Buzzcaf Private Limited, licensed address, FSSAI 11522079000056 |
| ☐ | FSSAI logo + licence number | In a colour that contrasts with the background |
| ☐ | Net quantity | "Net Quantity: 50 g" |
| ☐ | MRP | "MRP ₹___ (inclusive of all taxes)" |
| ☐ | Consumer care | Monitored phone number and email |
| ☐ | Batch / lot number | Printed at fill, not pre-printed |
| ☐ | Date of manufacture/packing and Best Before | DD/MM/YYYY |
| ☐ | Storage instructions | Say something useful: "Store in a cool, dry place. Keep tightly closed. Use a dry spoon." |
| ☐ | Country of origin | "Product of India" |
| ☐ | Font size | Minimum 3 mm height for Schedule II declarations (net qty, MRP, dates, consumer care) on a 50 g pack; check the letter height physically on the proof |
| ☐ | Old wording removed | Old labels said Buzzcaf manufactured and packed the product — no longer true |
| ☐ | Duo pack | A multi-piece package needs its own declarations: piece count, total net quantity, MRP of the combination |

## B. The listing page (Amazon **and** our website)

Since the October 2023 Legal Metrology amendment the listing itself must show, before purchase:

- Manufacturer / packer / brand-owner name and full address
- Common or generic name of the product
- Net quantity
- MRP inclusive of all taxes
- Consumer-care phone and email
- Country of origin
- Date of manufacture/best-before *where applicable* (Amazon asks for shelf-life declaration for Grocery)

The website product model must carry these as fields, not as free text buried in the description.

## C. Sign-off

Two people check the proof independently (Sudhansu + one other). Both initial the printed proof; scan it into the vault. Only then release to print.
