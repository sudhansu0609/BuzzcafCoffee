# SOP-07 Website order fulfilment (own stock)

Applies to orders on buzzcaf.com. Amazon orders are FBA and never touch us (SOP-06).

## Daily ritual (fixed time, e.g. 10:00)

1. **Open the website admin → Orders → Paid, unfulfilled.** Confirm payment status is *captured* in the gateway dashboard, not just "authorised".
2. **Pick** from own stock, oldest batch first (FEFO — first expiry, first out). Note the **batch number on the order** in admin. This is how a recall reaches the right customers (SOP-05).
3. **Pack**: jar wrapped (bubble/paper), in a rigid box with filler; the how-to card; the GST invoice (auto-generated by the site — CGST+SGST 2.5%+2.5% within Maharashtra, IGST 5% otherwise; HSN 2101 12). No "please rate us 5 stars" cards — ever.
4. **Ship** via Shiprocket (site pushes the order automatically; if not, create it manually). Choose prepaid courier by pincode serviceability; COD only if enabled with partial prepay.
5. **Mark shipped** in admin; the customer gets tracking by email/WhatsApp.
6. Update `qty_remaining` on the batch in Ops (SOP-12).

## Returns / RTO

- RTO parcels: open, check seal intact, restock only if the jar is sealed and undamaged; otherwise destroy and log the loss against the batch.
- Customer returns for quality: treat as a complaint (SOP-05) — get the batch number.

## Packaging stock

Keep four weeks of boxes, filler, tape and how-to cards. Reorder at two weeks.

## Records

Each order: order ID, date, items, batch numbers, invoice number (sequential, FY-prefixed, e.g. BZ/26-27/0001), courier AWB. The website keeps this; Ops keeps the batch side. Monthly, the order export feeds GST (SOP-08).
